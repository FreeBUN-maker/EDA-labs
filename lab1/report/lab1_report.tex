\section{Problem 3：Tree Covering 算法}
\subsection{(a) 关于 Tree Covering 算法的讨论}

\begin{enumerate}[label=(\roman*)]
  \item \textbf{树上的最优性。}
  在 Problem 2(c) 中，主输入（PI）节点是免费的，而该例的树化
  （treeifying）可以通过复制输入节点完成，因此没有额外面积开销。
  在一棵树上，各子树的最优解不受其上层节点和其他子树映射方案的影响，
  因此可以通过动态规划（DP）得到最优的树覆盖。

  \item \textbf{DAG 上的最优性丢失。}
  在 DAG 上直接运行 tree covering 算法不保证得到全局最优解。
  一棵子树根节点匹配到的 pattern tree，可能覆盖其他分支也会使用的节点。
  因而各子问题之间存在共享，映射问题不再完全解耦，
  独立求解各子问题的 DP 无法保证全局最优。

  \item \textbf{同时跟踪两种极性的作用。}
  有些库门的 pattern tree 自带反相边，其面积小于先将反相边全部用
  \code{inv1} 实现、再对剩余节点进行 tree covering 的总面积。
  如果对每条反相边都固定插入一个 \code{inv1}，就可能错过更便宜的局部覆盖方案。
\end{enumerate}
